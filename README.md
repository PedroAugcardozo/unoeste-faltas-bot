Bot de Acompanhamento de Faltas da Faculdade 🤖📚

Este projeto é um bot automatizado desenvolvido em JavaScript com Puppeteer que acessa o portal da faculdade, coleta informações sobre suas faltas em cada matéria e calcula quantas faltas você ainda pode ter antes de ser reprovado.

Funcionalidades ✨

Autenticação automática: Faz login no portal da faculdade usando suas credenciais.

Coleta de dados: Acessa a área de faltas e extrai a lista de matérias e a porcentagem de faltas.

Cálculo de faltas disponíveis: Calcula quantas faltas você ainda pode ter em cada matéria antes de atingir o limite permitido.

Resultados claros: Exibe os resultados no terminal ou pode ser configurado para salvar em um arquivo.

Pré-requisitos 📋

Antes de começar, você precisará ter instalado:

Node.js (v16 ou superior)

Git (para clonar o repositório)

Personalização 🛠️

Adicionar novas funcionalidades: Você pode expandir o bot para coletar outras informações, como notas ou horários de aula.

Automatizar execuções: Use ferramentas como cron ou node-schedule para rodar o bot automaticamente.

Salvar resultados: Modifique o código para salvar os resultados em um arquivo .txt ou enviar por e-mail.
